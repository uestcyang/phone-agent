# v0.1.0: Phone Agent Core Edition

Initial source release of an Android client and self-hosted task transport for a configured native agent CLI.

Included: administrator-approved device pairing and revocation; persisted message acknowledgements and deduplication; session replay; authenticated uploads/downloads; bounded command execution and artifact handling; Flutter client; reproducible tests and build instructions.

Excluded: maintainer deployment data, credentials, private presets, account/quota collectors, infrastructure repair, model accounts, voice service, incognito storage, native device tunnel and prebuilt APKs.

The reviewed original source archive is `PhoneAgent-core-source-660045d3.zip`.
SHA-256: `902a0d6cd8098aaca85332fcd484252421bcd596dab49e8a859563a91630fe90`.

The repository presentation commit adds documentation to the reviewed baseline and does not change application/server code. Release notes do not imply a tested commercial provider integration or real-device UI E2E.
