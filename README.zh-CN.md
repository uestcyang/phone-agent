# Phone Agent

### 用 Android 手机操作你自己的原生 AI Agent。

Phone Agent 是一个**自托管 Android 客户端与持久任务传输层**。手机配对后，把任务交给自己主机上的 Agent CLI；网络断开后可以重连、回放消息并取回产出文件。模型、工具和 Agent 循环仍由你现有的执行器负责。

[English](README.md) · [部署说明](docs/SETUP.md) · [测试范围](docs/VALIDATION.md) · [安全边界](SECURITY.md)

## 它解决什么

不是再造一个聊天壳或 Agent 框架，而是把“手机下达任务 → 主机执行 → 手机接收文件”的传输与交接做扎实。

| 场景 | 核心版机制 |
|---|---|
| 手机连接自己的 Agent | Flutter 客户端，显式配置服务端和原生 CLI 适配器 |
| 切网、断线后继续 | 客户端持久发件箱、服务端持久 ACK、按序事件回放 |
| 同一消息重投 | message-id 去重，相同 ID 的不同正文明确拒绝 |
| 取回真正的工作产物 | 带认证的上传、下载和输出文件检查 |
| 多设备授权 | 管理员批准配对、撤销设备、会话与文件访问隔离 |

**这不是在手机上运行大模型，也不是让 AI 自动点击其他手机 App。** Agent 执行在你配置的主机上。

任务执行中途遇到服务端重启，会被标记为中断，不会悄悄自动再执行一遍。对于付款、部署等外部副作用，传输层不能凭空提供“绝对只执行一次”的保证。

## 使用前提

需要 Android 手机、Flutter 构建环境、Linux 或 macOS 主机上的 Python 3.11+，以及你自己的可信执行器。没有内置模型账号，不需要本项目提供的托管服务。

先按[部署说明](docs/SETUP.md)安装依赖、在本地生成管理员令牌、配置执行命令、启动服务并构建客户端。没有令牌或执行命令时启动会被拒绝。默认地址不连接任何维护者机器。

`server/native_runner.py` 提供“stdin 输入提示、stdout 返回文本”的通用 CLI 适配边界。实际模型产品的非交互参数、权限和凭据需要自行配置，本项目不宣称已经实测所有商业 Agent 产品。

## 真实验证范围

核心版通过了 Linux 和 macOS 各 **37 项服务端测试**、**10 项 Flutter 测试**、合成原生命令适配测试，以及 Android debug 构建。服务端测试使用真实本地 HTTP/WebSocket 连接和子进程，不以纯 mock 冒充传输链路验证。

未宣称完成真实付费模型账户或实体手机界面的完整端到端验收。本次为源码版，不附预编译 APK。

## 公开范围

不包含私人角色、账号额度采集、基础设施修复、私人部署拓扑、运行数据和旧 Git 历史。独立核心服务端暂不实现实时语音、无痕存储和设备控制隧道。README 的能力范围以这份核心版为准，不以私人原型的全部功能充数。

远程部署应自行配置 HTTPS；原生执行器不等于 OS 沙箱，应放在权限受限的用户或容器中运行。详见[安全说明](SECURITY.md)。
